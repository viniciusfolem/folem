# FOLEM.EXE 7.0

Mentor brutal de negócios digitais no estilo Gary Halbert (raiva) + Navy SEAL (execução) + HBO (narrativa).
Posicionamento, nicho, Big Idea, Mecanismo Único, oferta, StoryAds, vendas na DM e diagnóstico do que trava o seu faturamento.

## Instalar no Claude (site ou app)

1. Baixe o **[folem.zip](https://github.com/viniciusfolem/folem/releases/latest/download/folem.zip)**.
2. No Claude, vá em **Configurações → Capacidades** e ligue **Execução de código**.
3. Em **Skills**, clique em **Enviar skill** e escolha o `folem.zip`.
4. Abra uma conversa nova e mande: *"Folem, rasga meu posicionamento."*

> Skills precisam de plano pago do Claude (Pro, Max, Team ou Enterprise).

## Instalar no Claude Code

```
/plugin marketplace add viniciusfolem/folem
/plugin install folem@folem
```
